# Data Sources and Lineage

## Market prices

`prices.csv` contains adjusted closes used for the listed-asset proxy portfolio. A sidecar `prices.csv.metadata.json` identifies whether the file was generated by the deterministic demo or downloaded from Yahoo Finance, when it was retrieved, and which series were requested.

Quality checks run on the raw frame before any imputation. Forward filling is limited to three rows and every affected ticker is reported in `imputation_audit` with raw missing, imputed, and remaining missing counts.

## Official RBA data

The `download-rba` command downloads two public Reserve Bank of Australia statistical tables:

| Dataset | RBA table | Curated series |
|---|---|---|
| AUD exchange rates | F11.1 | AUD/USD and AUD trade-weighted index |
| AUD zero-coupon curve | F17 | 0Y, 3M, 6M, 1Y, 2Y, 3Y, 5Y, 7Y, and 10Y yields |

The downloader writes a catalog containing the exact source URL, provider, UTC retrieval timestamp, row and series counts, observation range, and SHA-256 file hash. Downloaded data remains excluded from Git; the code and catalog construction are reproducible. Users must review source terms before redistributing raw observations.

## Control meanings

- `missing_required_tickers`: configured series absent from the raw file.
- `duplicate_dates`: duplicate raw observation dates.
- `missing_price_cells`: raw missing values before forward filling.
- `nonpositive_prices`: invalid prices at or below zero.
- `max_calendar_gap_days`: largest gap between observations.
- `data_age_days`: calendar days from the newest observation to execution date.
- `source_type`: `synthetic_demo`, `yahoo_finance`, or `unknown` for legacy/unlabelled files.

Synthetic data is intentionally stale relative to live reporting and can fail the freshness check. That is evidence that the control is active, not a pipeline failure.
